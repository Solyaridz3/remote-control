# Remote — тачпад iPhone для Windows, без Mac

Запустите приложение на Windows 11, а на iPhone 14 откройте мобильный интерфейс в Safari. **Mac, Xcode, Apple Account, установка `.ipa` и интернет не нужны.** Интерфейс, стили и скрипты встроены в Windows `.exe`; облако и сторонние сайты не используются.

## Запуск

1. Распакуйте `dist/RemoteController-Windows.zip` и запустите `RemoteController.exe`. Либо запустите готовый `dist/RemoteController.exe`.
2. Подключите iPhone и ноутбук к одной домашней Wi-Fi сети. Ноутбук также может быть подключён к тому же роутеру кабелем.
3. Если Windows спросит разрешение брандмауэра, разрешите приложению доступ в **частных сетях**. Приложение не меняет брандмауэр автоматически.
4. В окне Windows найдите ссылку вида `https://192.168.1.150:49732/`. **Откройте именно показанную на вашем ноутбуке ссылку в Safari на iPhone**, включая `https://` и порт `:49732`. Пример в инструкции не является вашим адресом.
5. Нажмите «Подключить ноутбук», введите 12 символов кода из окна Windows и оставьте включённым **«Запомнить устройство»**. При желании укажите понятное имя телефона. После подключения появится индикатор «В сети».

Перед первым подключением выполните раздел «Настройка HTTPS» ниже. Оставьте окно Windows открытым. Для запуска не нужны права администратора или .NET SDK; используется .NET Framework 4.x, сборка x64. Веб-интерфейс рассчитан на Safari iOS 16+.

## Настройка HTTPS

В Windows нажмите **«Защищённое подключение»**. На iPhone откройте показанный там адрес настройки `http://IP:49732/`, скачайте профиль сертификата, проверьте полный SHA-256 отпечаток сертификата профиля по окну Windows и установите его. Затем включите полное доверие проверенному сертификату: **Настройки → Основные → Об этом устройстве → Доверие сертификатам**. Не устанавливайте сертификат при несовпадении отпечатка и не обходите предупреждения Safari.

После настройки откройте **HTTPS-ссылку** из главного окна Remote. На новом HTTPS-адресе потребуется один раз ввести код и запомнить устройство: хранилище старого HTTP-адреса не переносится через незащищённую сеть. Существующие сохранённые устройства на ПК сохраняются. Старый значок iPhone ведёт на инструкцию; добавьте новый значок из HTTPS-страницы Safari.

Центр доверия уникален для установки Remote на этом ПК. Его закрытый ключ и ключ сервера хранятся в `%LOCALAPPDATA%\RemoteController\tls` под защитой DPAPI текущего пользователя Windows. Они не входят в профиль, ZIP или исходники. Обновления приложения не меняют центр доверия; серверный сертификат обновляется при смене IP или приближении срока действия. Профиль можно сохранить из окна Windows и передать по доверенному каналу. Чтобы убрать доверие на iPhone, удалите профиль Remote. Самостоятельная установка профиля и включение доверия выполняются пользователем.
## Значок на главном экране iPhone

Safari → **Поделиться → На экран Домой → Добавить**. Если есть переключатель «Открывать как веб-приложение», включите его. Страница содержит manifest и метаданные для отдельного окна; поведение зависит от версии iOS. [Инструкция Apple](https://support.apple.com/ru-ru/guide/iphone/iphea86e5236/ios).

Ярлык загружает интерфейс с ноутбука, поэтому сервер должен быть запущен. При смене IP откройте новую ссылку. Автономное кеширование и service worker не используются: для управления всё равно нужен доступный ноутбук.

## Подключение без повторного кода

После первого сопряжения телефон сохраняет персональный случайный ключ. При открытии той же страницы и при возвращении в Safari он подключается автоматически, если Windows-приложение запущено. Перезапуск ноутбука или приложения не требует нового кода: Windows сохраняет список устройств отдельно от `.exe`.

- Если ноутбук временно недоступен или занят другим телефоном, страница повторяет подключение с паузами. Сохранённый ключ остаётся на телефоне.
- Кнопка отключения на телефоне останавливает автоподключение до следующего нажатия «Подключить без кода» либо нового открытия страницы.
- Windows → **«Сохранённые устройства» → выбрать телефон → «Забыть выбранное устройство»** отзывает ключ и немедленно отключает этот телефон. После этого потребуется код для нового сопряжения.
- Смена обычного кода не удаляет сохранённые устройства. Она останавливает текущую сессию; сохранённый телефон может подключиться кнопкой без кода. Для отзыва доступа используйте «Забыть».
- Можно не включать запоминание: тогда действует одноразовое подключение по коду.
- Ключ относится к браузерному хранилищу текущего адреса. Очистка данных браузера, другой браузер, приватный режим или другой IP/порт могут потребовать первого сопряжения заново. Для стабильного адреса можно зарезервировать IP ноутбука в домашнем роутере.
- Если браузер запрещает сохранение ключа, подключение остаётся рабочим, но интерфейс предупреждает, что после закрытия страницы понадобится код.

На Windows имена и SHA-256 хеши ключей хранятся в зашифрованном Windows DPAPI контейнере в `%LOCALAPPDATA%\RemoteController\devices.json`. Исходные ключи и обычный код в этом файле не сохраняются. Одновременно можно запомнить до 32 устройств; управлять ноутбуком — только с одного. Если файл повреждён, приложение сохраняет его для восстановления и отказывает старым ключам. Подключение по текущему коду без запоминания продолжает работать.

## Управление

- **Экран:** переключатель «Экран» на главном экране показывает область рабочего стола вокруг курсора прямо в тачпаде. Касания, двойной клик, выделение, перетаскивание, прокрутка и растягивание продолжают работать поверх изображения. Пока курсор в центральной части, область просмотра неподвижна; у края она плавно следует за ним. Размер тачпада не меняется. Частота адаптивная — до 60 кадров/с; при медленной связи снижаются частота и качество. Фактическая частота показана внизу тачпада. При открытии пункта управления или клавиатуры передача приостанавливается и возобновляется после возврата. При отключении или сворачивании телефона трансляция выключается; автоматически она не включается. Кадры не сохраняются на диск и передаются только подключённому телефону по локальной сети. Защищённое содержимое Windows может отображаться чёрным.

- **Выделение и перетаскивание:** быстро коснитесь тачпада дважды; на втором касании удерживайте палец и ведите его. После движения можно поднять палец на время до 0,8 секунды, переставить его в любое место тачпада и продолжить без скачка курсора. Для завершения подождите 0,8 секунды либо коротко коснитесь тачпада. Во время паузы показывается подсказка «Переставьте палец». Два коротких касания работают как двойной клик. Добавление второго пальца, переход к кнопкам, отмена касания и отключение связи отпускают кнопку мыши.

- **Лупа:** включение и выключение — переключателем «Лупа» на главном экране рядом с клавиатурой. Радиус, увеличение и положение настраиваются в пункте управления. Круглая лупа следует за курсором; радиус регулируется от 80 до 280 пикселей, увеличение — от 1,5× до 4×. Можно выбрать положение вокруг курсора или сбоку, чтобы не закрывать место клика. Размер, увеличение и положение сохраняются на телефоне. При отключении, потере связи или остановке приложения лупа выключается; после подключения включите её вручную. Лупа увеличивает участок экрана, сохраняя масштаб в программах, и пропускает клики к окнам под ней. Содержимое экрана обрабатывается Windows локально и не передаётся телефону. Защищённые окна Windows могут не отображаться в лупе.

- Основной экран — тачпад на всю ширину телефона, заполняющий всё место от верхней панели до нижнего края. В обычной вкладке учитывается видимый viewport Safari; в установленном приложении iPhone — полная высота экрана, если WebKit исключает системную область из viewport. Безопасные отступы применяются только к верхним кнопкам и нижней подсказке, а не вычитаются из рабочей зоны дважды. Размер обновляется при повороте, изменении viewport и возвращении в приложение.
- Кнопка «Пункт управления» открывает отдельный экран со всеми кнопками подключения, громкости и настройками. «Назад к тачпаду» возвращает к основной рабочей зоне. Переключение экранов сохраняет соединение и корректно завершает активный жест.
- Кнопка со значком клавиатуры на главном экране открывает поле ввода и стандартную клавиатуру iPhone. Вводимый текст виден на телефоне и сразу передаётся в активное поле Windows.
- Один палец — курсор; короткое касание — левый клик.
- Движение двумя пальцами — вертикальная прокрутка; касание двумя пальцами — правый клик.
- Разведение двух пальцев — плавное растягивание изображения, сведение — уменьшение. Сначала наведите курсор на изображение в нужной программе. Жест передаётся через виртуальный precision-тачпад Windows; клавиши Ctrl и колесо для него не используются.
- Прокрутка и растягивание различаются по направлению движения пальцев. Чтобы перейти от уже начатой прокрутки к растягиванию, отпустите пальцы и начните новый жест.
- В пункте управления — «Тише», включение/выключение звука и «Громче».
- «Подключить ноутбук» открывает ввод кода; кнопка питания отключает связь.
- «Жесты и настройки» — чувствительность и подсказки. Чувствительность и выбранный ключ устройства сохраняются в браузере; обычный код очищается после подключения.
- «Плавный курсор» включён по умолчанию: небольшое сглаживание движения, сохранение дробных перемещений и отправка на каждом кадре браузера. Настройка сохраняется; её можно выключить для более резкой реакции. Порог начала движения уменьшен с 7 до 2 пикселей. При отпускании пальца остаток движения отправляется сразу, без инерционного продолжения.
- При сворачивании Safari, уходе со страницы или блокировке телефона связь прерывается. Сохранённый телефон подключится снова автоматически при возвращении.
- Автоматическое выключение экрана телефона не блокируется: локальная HTTP-страница не рассчитывает на Screen Wake Lock.

Bluetooth, комбинации клавиш, горизонтальная прокрутка и показ текущего процента громкости не реализованы.

## Клавиатура iPhone

1. Тачпадом нажмите нужное поле ввода на ноутбуке, чтобы поставить туда курсор.
2. На главном экране Remote нажмите значок клавиатуры рядом с «Пункт управления».
3. Печатайте обычной клавиатурой iPhone. Текст отображается в поле телефона и сразу вводится на ноутбуке. Поддерживаются кириллица, удаление, автокоррекция, вставка и многострочный текст.
4. Нажмите «Готово», чтобы закрыть поле и вернуться к тачпаду. Перед закрытием приложение ждёт подтверждения последних изменений.

Каждое открытие клавиатуры начинает новый фрагмент: ранее введённый текст на ноутбуке не удаляется. Поле телефона не читает содержимое ноутбука — показывает только текущий набираемый фрагмент. Пока вводите или правите этот фрагмент, не меняйте поле и положение курсора на ноутбуке другим способом. При редактировании середины фрагмента передаётся замена изменившегося хвоста.

Составные символы сначала завершаются в клавиатуре iPhone, затем отправляются в Windows. Обычный текст передаётся через Unicode, не зависит от выбранной раскладки Windows и не использует буфер обмена. Поведение Backspace для сложных emoji/комбинируемых символов зависит от редактора Windows. Enter передаётся как обычная клавиша Enter: в некоторых приложениях он может отправить сообщение, а не вставить перенос строки.

Введённый текст не сохраняется приложением в файл или localStorage. При потере связи локальный черновик остаётся видимым, ввод блокируется и не повторяется автоматически после подключения. Чтобы продолжить, закройте окно клавиатуры и откройте его заново. Размер текущего фрагмента ограничен 8192 UTF-16 единицами. Управление в окнах с повышенными привилегиями имеет те же ограничения, что и курсор.

Результат растягивания зависит от поддержки pinch в программе под курсором. Windows может интерпретировать жест по правилам этой программы. Также нужна версия Windows с API `CreateSyntheticPointerDevice2`: при отсутствии API интерфейс сообщает об ограничении, а курсор и громкость продолжают работать. На этой машине API обнаружен и виртуальный тачпад успешно создан и удалён без отправки контактов. При отпускании пальца, отмене жеста, обрыве связи, смене кода или остановке сервера виртуальные контакты освобождаются.

## Окно Windows

- Показывает локальные ссылки и код. Адреса обновляются автоматически.
- «Копировать ссылку» копирует первую ссылку. Если есть VPN или виртуальные адаптеры, выберите адрес домашней сети.
  - «Отключить / новый код» останавливает текущую сессию и меняет код; сохранённые ключи продолжают действовать.
  - «Сохранённые устройства» позволяет отозвать ключ конкретного телефона.
  - «Выключить приём» закрывает все соединения и выключает страницу. Приём можно включить снова.
- Закрытие окна завершает сервер. Приложение не устанавливает службу. Ярлык автозапуска запускает его свёрнутым после входа в Windows.

## Доступ и ограничения

**Управление, код, ключи сопряжения, вводимый текст и экран защищены HTTPS/WSS (TLS 1.2).** Safari должен доверять проверенному сертификату именно вашего ПК. На HTTP доступны только инструкция и публичный профиль сертификата; незашифрованные команды, WebSocket и ресурсы приложения отклоняются. Не обходите предупреждения сертификата и не открывайте порт в интернет. Шифрование не защищает от вредоносного ПО на самих устройствах.

- Код — 12 шестнадцатеричных символов из криптографического генератора; меняется при запуске и вручную.
- До проверки кода или персонального ключа команды не исполняются. В каждый момент допускается один управляющий клиент.
- После пяти неверных попыток действует общий перерыв на 30 секунд для непроверенных подключений. Правильный сохранённый ключ продолжает приниматься даже во время этого перерыва. Страница остаётся доступной.
- Проверяются HTTP Host и WebSocket Origin. Доменные имена и reverse proxy не поддерживаются: используйте числовой IP из окна Windows.
- Ограничены число соединений, размер HTTP/JSON/WebSocket-сообщений, значения движения и ожидание ответа.
- Сервер не раздаёт произвольные файлы и не принимает команды оболочки.
- `SendInput` работает в обычном пользовательском сеансе. Экран блокировки, UAC и окна с более высокими привилегиями не поддерживаются. Не запускайте сервер от администратора ради обхода этого ограничения.

## Если не открывается или не подключается

1. Проверьте, что приём включён, а ссылка начинается с `https://` и содержит правильный IP и порт `49732`. `localhost` и `127.0.0.1` на iPhone указывают на сам телефон и не подходят.
2. Проверьте разрешение в брандмауэре Windows для приложения в частной сети. Системный запрос подтверждается вручную.
3. Если Safari запрашивает разрешение локальной сети, разрешите его для этого подключения.
4. Гостевой Wi-Fi и AP/client isolation могут запрещать связь между устройствами. Используйте основную домашнюю сеть.
5. Проверьте VPN и другие адреса в окне Windows. Не вводите внешний адрес роутера.
6. Обновите страницу после замены Windows `.exe`, затем подключитесь по актуальному коду. После пяти неверных попыток подождите 30 секунд.
7. Не открывайте два управляющих окна одновременно. Отключите прежнее устройство или смените код в Windows.

## Сборка и проверка

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1 -Test
```

Сборка использует встроенный компилятор C# .NET Framework. Для JavaScript-тестов нужен Node.js. Все веб-файлы включаются в `.exe` ресурсами; при запуске рядом с ним не нужны `web/`, Node.js или дополнительные библиотеки.

Проверено:

- Windows `.exe` собран.
- **65 тестов C#**: протокол, ресурсы, авторизация, pinch, сохранённые устройства, Unicode-пакеты клавиатуры, кириллица/суррогатные пары, подтверждения редактирования, лимиты и запрет дубликатов.
- **68 JavaScript-тестов**: жесты, сглаживание, запоминание, высота экрана, клавиатура, автокоррекция, IME, emoji, длинный текст, подтверждения, закрытие и обрыв связи без повторной отправки.
- В настоящем браузере проверены код, три команды громкости, клик, движение и отключение. Для нового интерфейса проверены переход в пункт управления и возврат. Тачпад заполняет оставшуюся после верхней панели высоту; фиксированная высота 70% и квадратная форма больше не применяются.
- В браузере также проверено первое сопряжение с галочкой «Запомнить устройство» и автоматический вход после перезагрузки страницы без ввода кода.
- Кнопка клавиатуры, фокус поля, отображение кириллицы, подтверждение ввода и возврат к тачпаду проверены в браузере с тестовым приёмником. Стандартная экранная клавиатура и особенности IME физического iPhone в этой среде не проверены.

Сетевые тесты и браузерная проверка используют имитацию `IInput`: реальный курсор и громкость не меняются. Физический iPhone 14 и реальный системный ввод требуют проверки на ваших двух устройствах; мобильный viewport не заменяет тест Safari iOS.

Предпросмотр без управления компьютером:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\preview.ps1
```

Откройте напечатанную ссылку на порту `49733`, используйте напечатанный тестовый код. Команды только записываются в консоль. Остановка — Ctrl+C. Рабочий `.exe` использует порт `49732` и настоящий системный ввод.

Упаковка:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\package.ps1
```

## Автозапуск Windows

`scripts/update-shortcuts.ps1` создаёт или обновляет два ярлыка текущей сборки: на рабочем столе и в папке автозагрузки текущего пользователя. После входа в Windows Remote запускается свёрнутым (`--minimized`), а ярлык рабочего стола открывает обычное окно. После каждой новой сборки и упаковки запускайте этот скрипт; сохранённые устройства остаются в отдельном хранилище и не удаляются. Для отключения автозапуска можно отключить RemoteController в настройках приложений автозагрузки Windows.
